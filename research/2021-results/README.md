# 2021 parliamentary-election results — verified source data

Self-contained snapshot of the official 2021 Cypriot parliamentary-election
data used as the reference fixture for the simulator (see
[src/lib/data/results-2021.ts](../../src/lib/data/results-2021.ts) and
[tests/simulator.test.ts](../../tests/simulator.test.ts)).

Everything here is **cached locally** — re-running `verify_seats.py` does not
hit the network.

## Layout

```
2021-results/
├── verify_seats.py                          # aggregates + checks; writes aggregated/
├── raw/
│   ├── parliamentary_2021.csv               # ballot-box-level votes (source of truth)
│   ├── parties.json                         # party registry
│   ├── districts.json                       # district registry
│   ├── results.json                         # full nested results (district → town → centre → box)
│   ├── results_summary.txt                  # MOI press release with national tallies
│   ├── centers.json                         # polling-room registry
│   ├── election_centers.json                # polling-place registry
│   ├── parishes.json                        # parish registry
│   ├── towns.json                           # municipality / community registry
│   ├── elected_mps_2021.json                # parsed list of 56 elected MPs (district + party)
│   └── elected_mps_2021_source.html         # original sigmalive article (provenance)
└── aggregated/
    ├── votes_per_party_per_district.json    # generated by verify_seats.py
    └── seats_per_party_per_district.json    # generated by verify_seats.py
```

## Why both votes and seats?

The data-portal CSV publishes **votes**, not seats — seat allocation is the
output of Cyprus's three-stage reinforced-PR algorithm. The elected-MP roster
from the sigmalive article gives the **final published seat assignment per
district**, which is the ground truth the simulator must reproduce.

`verify_seats.py` cross-checks these two sources and proves the seat tally is
internally consistent with the six-district seat allotment
(20/12/11/6/4/3 = 56).

## Running the verifier

```bash
python3 verify_seats.py
```

Exits non-zero on any failure. On success, regenerates the two files under
`aggregated/`:

- `votes_per_party_per_district.json` — votes per district per party, sorted
  by national vote share.
- `seats_per_party_per_district.json` — seats per district per party, sorted
  by total seats (DISY 17, AKEL 15, DIKO 9, ELAM 4, EDEK 4, DIPA 4, Greens 3).

## Reconciliation with `results-2021.ts`

Every (district, party) seat cell in
[src/lib/data/results-2021.ts](../../src/lib/data/results-2021.ts) matches the
tally produced here. The simulator's integration test
([tests/simulator.test.ts](../../tests/simulator.test.ts)) is the runtime
check; this folder is the **paper trail** behind those numbers.
